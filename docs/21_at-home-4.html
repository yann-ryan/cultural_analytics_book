26  Home exercise 4

Instructions

Checkpoint: submit by Tuesday 10 November

This exercise is one of the two graded checkpoints (pass/fail). You pass by making a genuine attempt at all of the exercises - they don’t have to be perfect.

Do the at-home exercises in R-Studio, in your cultural_analytics project (see Installing R and RStudio). Download the files for this exercise from Brightspace and save them in your project folder. Create a new .Rmd file (use File -> New File -> R Markdown).

I advise saving the new file straight away. Because you’ll submit this file as an assignment, use a standardised name: exercise_4_lastname_firstname. Regularly re-save the file.

When you have finished the exercise (or part of it), ‘knit’ the file. Export the .Rmd and the html as a .zip file, and upload this to the assignment area.

If you can’t knit the file because of an error, comment out the code which doesn’t work using #, and make a note of what went wrong.

What to submit

Your .Rmd file should have a section for each of the ten exercises. Start each one with a heading, such as ## Exercise 1. Each exercise asks for one or both of these:

  • Code: a code chunk that does what the exercise asks. When you knit the file, its result appears underneath, so you don’t need to copy any numbers out of it.
  • Write: an answer in your own words, in a sentence or two. Put it as normal text in the .Rmd, below the code chunk, not inside the chunk. Use the result of your code to answer it.

For example:

## Exercise 2

```{r}
dialogue <- characters |>
  left_join(meta, by = 'script_id')

nrow(dialogue)
```

The joined dataframe has 23,048 rows, the same as `characters`, because each character belongs to exactly one film.

Each exercise also gives a number in brackets, so you can check that your code is right. You don’t need to write these numbers down in your answer.

The data

Today we will use a dataset from an article written for The Pudding: Hannah Anderson and Matt Daniels, “Film Dialogue from 2,000 screenplays, Broken Down by Gender and Age”. Have a look at the article first: it asks the same questions as these exercises.

The article used screenplays to understand the gender balance of films, and how it has changed over time. The data covers 2,000 films from 1929 to 2015. It comes in three files:

  • character_list5.csv: one row per character, with the script_id of the film, the character’s name, the number of words they speak, their gender and their age.
  • meta_data7.csv: one row per film, with the same script_id, plus the imdb_id, title, year and gross (box office takings). You can ignore the lines_data column.
  • imdb_genre.csv: one row per film, with its genres, taken from IMDb. It doesn’t have the script_id, but its tconst column holds the same IMDb ID as imdb_id in the metadata.

Dialogue is measured in words, not lines.

Exercises

Exercise 1: load the data

Code: load the tidyverse package with library(), and read all three files into R. Save them as objects called characters, meta and genres.

Exercise 2: join the characters to the films

Code: use left_join() to join meta to characters, using script_id as the key, so that each character has the title and year of their film alongside them. Save the result as dialogue, and show how many rows it has with nrow(dialogue). (23,048)

Write: why does dialogue have the same number of rows as characters?

Exercise 3: how is gender recorded?

Code: use count() on the gender column of dialogue. (Three values: f 6,911, m 16,132 and ? 5)

Write: what do you think each of the three values means?

Exercise 4: the overall balance

Code: using group_by() and summarise(), calculate the total number of words spoken by each gender, across all the films. (f 5,877,657 words)

Write: roughly what share of all the dialogue is spoken by women? You can work it out from your result with a calculator, or try it in R with mutate(). (About 28%)

Exercise 5: one row per film

Make a new dataframe, called films, with one row for each film, and two columns counting the words spoken by women and by men in that film.

This needs a trick. First, use mutate() and if_else() to make two new columns: female_words, which holds the character’s words if they are female and 0 if not, and male_words, which does the same for men. Then group by film and add up those two columns with summarise().

Code: copy this code into your file, run it and look at the result. (2,000 rows)

films <- dialogue |>
  mutate(female_words = if_else(gender == 'f', words, 0),
         male_words = if_else(gender == 'm', words, 0)) |>
  group_by(script_id, imdb_id, title, year) |>
  summarise(female = sum(female_words),
            male = sum(male_words))

Code: run count(meta, title), and arrange the result so the largest counts are at the top.

Write: answer these two questions.

  • Why do we group by script_id, and not just by title? Use the result of count() to explain.
  • Why do we also put imdb_id, title and year in the group_by(), if script_id is already enough to make one row per film?

Exercise 6: which films have more female dialogue?

Code: add two new columns to films with mutate(), and save the result:

  • prop_female: the share of the dialogue spoken by women. This is the female words divided by the female and male words added together.
  • balance: use case_when() to make this ‘more female’ if there are more female words than male words, ‘more male’ if there are more male words, and ‘equal’ if they are exactly the same.

Then count the values in balance. (304 more female, 1,695 more male, 1 equal)

Code: filter films to find the one film where the dialogue is equal.

Write: which film is it?

Exercise 7: Star Wars

Code: filter films to keep only the Star Wars films, and arrange them by prop_female. (7 films)

Tip

All the Star Wars titles start with ‘Star Wars’. You can find them with str_detect(), from the optional chapter on text patterns: filter(str_detect(title, 'Star Wars')).

Write: which Star Wars film has the highest share of female dialogue, and which the lowest? How do they compare with the share for all films that you found in exercise 4? (The highest is The Force Awakens, at about 28%)

Exercise 8: change over time

Code: use mutate() to make a decade column with floor(year / 10) * 10 (this rounds 1977 down to 1970). Then group by decade, and for each decade calculate the number of films, and the share of female dialogue: the total female words divided by the total of all the female and male words. (About 21% in the 1970s, 31% in the 2010s)

Write: has the share of female dialogue changed over time? Are there decades where you should be careful about drawing conclusions, and why?

Exercise 9: genre (more of a challenge)

Which genres have the most female dialogue?

Code: join genres to films. The key columns have different names, so use by = c('imdb_id' = 'tconst'), as in the joins chapter. Save the result.

Look at the genres column. Most films have more than one genre, separated by commas, such as “Comedy,Romance,Thriller”. To count each genre separately, they need to be split up.

Code: add separate_longer_delim(genres, ',') to split them up, and show the number of rows before and after. (2,000 before, 5,192 after)

Write: why does the number of rows go up?

Code: now group by genre, and calculate the number of films and the share of female dialogue, as in exercise 8. Arrange the result from highest to lowest share. (The highest is Romance, at about 40%)

Write: which genre has the highest share of female dialogue, and which the lowest? Why might a genre with very few films give a misleading answer?

Exercise 10: extra challenge

Code: make the same one-row-per-film dataframe as in exercise 5 a different way, without the if_else() trick. Group by film and gender, and summarise() the words. Then use pivot_wider() (from the tidying data chapter) to turn the genders into columns. (2,000 rows)

Hints: films with no women in them will get an NA. Look up the values_fill argument of pivot_wider() to fill these with 0 instead. And what should you do about the ? gender first?
